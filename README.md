# SZUP_projekat_kalkulator

Ovaj projekat je jednostavan kalkulator implementiran u Javi, napravljen kao deo zadatka iz predmeta *Sistemi za upravljanje dokumentima*.
Projekat demonstrira osnovne matematičke operacije (sabiranje, oduzimanje, množenje i deljenje) i integraciju NetBeans okruženja sa GitHub repozitorijumom kroz rad sa granama, commit-ovima i verzijama.
